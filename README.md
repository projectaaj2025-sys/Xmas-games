# Снежный переполох

Новогодние игры для одного экрана, проектора и телефонов участников. Викторина также доступна для скачивания как презентация PowerPoint на 173 слайда.

## Запуск на компьютере ведущего

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:4173`. Чтобы присоединить телефоны и второй экран, компьютер ведущего и мобильные устройства должны быть в одной Wi-Fi сети. Ведущий открывает режим «Круг с телефонами» — сайт покажет QR-код и код комнаты. Участники сканируют QR-код либо открывают локальную ссылку ведущего и вводят код вручную. Компьютер ведущего должен оставаться включённым, а локальный firewall — разрешать подключения к порту 4173.

QR-ссылка ведёт на локальный адрес компьютера, например `http://192.168.1.24:4173/player.html?room=ABCDE`. Если на устройстве открыта только страница `player.html`, код комнаты можно ввести вручную.

## Публикация на GitHub Pages

GitHub Pages может раздавать статическую версию сайта, но не запускает Node.js и WebSocket. Одиночные игры работают, однако синхронизация с отдельным экраном и подключение телефонов работают только при запуске Node-сервера (локально в одной сети или на отдельном WebSocket-хостинге).

## Угадай мелодию

В игре три участника, три поля по четыре категории и пять нот в каждой и отдельная суперигра. Стоимость первой доски повторяет расположение цифр на образце. Темы меняются от раунда к раунду; песни в каждом из трёх языковых режимов разложены по темам. Из-за ограниченного каталога некоторые песни повторяются: они отмечены в раскрываемом списке ведущего.

Ведущий выбирает ноту, запускает запись и назначает очки. За одну ноту каждый игрок может получить начисление или штраф только один раз. В суперигре ведущий выбирает финалиста, запускает таймер на 30 секунд и помечает ответы: семь верных ответов — победа, первая ошибка или истечение времени — проигрыш; пропущенная мелодия возвращается в очередь. Это адаптация телевизионного формата: все три основных тура используют одинаковое поле с нотами, а не телевизионные торги и нарастающую стоимость. Описание классических правил: https://www.vremya.tv/announce/12272.

Для двух русских мелодий и семи традиционных английских есть встроенные инструментальные записи. Прочие русские записи доступны по внешним ссылкам, некоторые — через YouTube; они не скачаны на сайт. Английские записи также доступны через YouTube. Внешние плееры требуют интернет и могут быть недоступны из-за региональных ограничений. На GitHub Pages второй экран недоступен, но игра работает на одном устройстве; синхронизация со вторым экраном требует Node-сервера.

Кнопки заставки и перехода используют файлы, обозначенные в найденных источниках как музыка передачи. Авторские права и разрешение на повторную публикацию этих файлов и двух русских инструментальных записей не подтверждены; перед публичным использованием необходимо их проверить. Источники записаны в `assets/melody/ATTRIBUTION.md`.

## Новогодняя игра

После краткой инструкции кнопка «Начать игру на сайте» запускает самостоятельную браузерную адаптацию: три вопроса викторины, три вопроса о кино, три музыкальных задания и три слова с буквами. Есть общий счёт и кнопка полного экрана. Музыкальный раунд использует встраиваемые записи YouTube и требует интернета. Киноотрывков нет. Вопросы и медиа отличаются от оригинала: это не конвертация презентации.

Оригинальная игра — презентация PowerPoint размером 351 МБ, доступная отдельно на Google Диске вместе с инструкцией автора. Из-за размера Google может предложить скачать файл вместо просмотра; для интерактивности используйте показ слайдов в PowerPoint. На странице сохранены отдельные ссылки на презентацию и комплект.
