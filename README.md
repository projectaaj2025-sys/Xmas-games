# Снежный переполох

Новогодние игры для одного экрана, проектора и телефонов участников. Викторина также доступна для скачивания как презентация PowerPoint на 173 слайда.

## Запуск на компьютере ведущего

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:4173`. Чтобы присоединить телефоны и второй экран, компьютер ведущего и мобильные устройства должны быть в одной Wi-Fi сети. Ведущий открывает режим «Круг с телефонами» — сайт покажет QR-код и код комнаты. Участники сканируют QR-код либо открывают локальную ссылку ведущего и вводят код вручную. Компьютер ведущего должен оставаться включённым, а локальный firewall — разрешать подключения к порту 4173.

QR-ссылка ведёт на локальный адрес компьютера, например `http://192.168.1.24:4173/player.html?room=ABCDE`. Если на устройстве открыта только страница `player.html`, код комнаты можно ввести вручную.

## Публикация на GitHub Pages

GitHub Pages может раздавать статическую версию сайта, но не запускает Node.js и WebSocket. Одиночные игры работают, однако синхронизация с отдельным экраном и подключение телефонов работают только при запуске Node-сервера (локально в одной сети или на отдельном WebSocket-хостинге).

## Угадай мелодию

В игре четыре тура по девять нот и три участника. В начале выберите русскую, английскую или смешанную подборку; смена подборки сбрасывает очки и сыгранные ноты. Нажмите ноту, откройте подсказку ведущему и включите музыку. Ведущий начисляет или снимает указанное количество баллов и завершает мелодию. Кнопки туров позволяют вернуться к ранее начатому туру, не теряя счёт.

В комплекте есть семь коротких инструментальных фрагментов традиционных англоязычных мелодий. Для остальных нот, включая русскую подборку, аудио пока нет: можно выбрать свой аудиофайл на устройстве ведущего или воспроизвести запись отдельно. Кнопка «Заставка» включает свободную музыку; при смене тура звучит переход. Это не оригинальная музыка телешоу. Источники и лицензии приведены в `assets/melody/ATTRIBUTION.md`. Файлы хранятся только до закрытия игры или обновления страницы. Названия категорий оформлены по образцу игрового поля и не гарантируют соответствие прежнего списка песен этим жанрам. На втором экране показывается поле и счёт, а ответ — только после нажатия ведущим «Показать ответ на экране». Для второго экрана нужен Node-сервер; на GitHub Pages игра работает на одном устройстве.
