# Кандидаты для будущих новогодних игр

Большинство этих фрагментов подключено к новогодней игре; `ru-hlopya.mp3` сохранён как запасная версия и пока не используется. Каждый — 25 секунд исходной записи с 20-й секунды, MP3 128 кбит/с. Файлы декодированы и проверены на наличие звука. Название и исполнитель сверены с метаданными источника; это не заменяет прослушивания каждого фрагмента и окончательной проверки узнаваемости.

Источники содержат записи известных исполнителей. Наличие файлов в этих репозиториях не подтверждает разрешение правообладателей на публичное распространение.
